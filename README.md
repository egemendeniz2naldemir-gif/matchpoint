# 🥊 MatchPoint — Workout & Round Tracker

MatchPoint is a lightweight, responsive web application designed for boxers, combat sports athletes, and HIIT enthusiasts. It acts as an interval training timer that dynamically tracks rounds, rest intervals, and provides real-time voice prompts for smooth training sessions.

## ✨ Key Features

- **Customizable Intervals:** Easily set Round Duration, Rest Time, and Total Rounds.
- **Voice-Assisted Prompts:** Uses browser SpeechSynthesis to announce commands like *"FIGHT"*, *"REST"*, and *"READY"*.
- **Dynamic Visual Feedback:** Color-coded screen updates according to training state (Fight, Rest, Pause).
- **Workout History Log:** Saves completed workouts locally using `LocalStorage` to track total training sessions over time.
- **Fully Responsive:** Works smoothly on desktop and mobile devices.

## 🛠️ Built With

- **HTML5** — Semantic page structure
- **CSS3** — Custom properties, Flexbox, Grid, and dark mode UI
- **JavaScript (Vanilla)** — Timers, Web Speech API, LocalStorage integration

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open `box.html` in any modern web browser.
3. Set your preferred round duration and rest times, then click **Start Workout**!
